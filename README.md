# NoeApps

Código fuente y copia mantenible de la web pública [noeapps.com](https://noeapps.com), alojada actualmente en **ChatGPT Sites**.

> Estado de sincronización: en curso. Este repositorio se está completando con el código, contenido y recursos necesarios para reproducir la web sin depender del alojamiento de Sites.

## Objetivo

- Mantener `noeapps.com` publicado en ChatGPT Sites.
- Conservar en GitHub una copia completa y versionada del código de la web.
- Poder reconstruir o migrar la web a otro hosting si fuese necesario.
- Mantener separada la web corporativa del código de cada aplicación.
